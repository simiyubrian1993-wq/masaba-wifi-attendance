# MASABA WiFi Employee Attendance System

Mobile-first attendance system for MASABA WiFi.

Features:
- Employee name
- Sign in / sign out
- GPS location
- Camera photo
- Working-hours calculation
- Attendance history
- Admin dashboard
- CSV export
- Mobile-friendly interface

## Important
